# ALE Workbench v1.0 — 用户指南

## 打开桌面壳

双击桌面快捷方式「ALE Workbench」（或开始菜单 / 安装目录的 `ALE-Workbench-Launcher.exe`）。

## 首次使用

桌面壳会自动检测安装目录下的项目（`start-workbench.ps1` 与壳同目录）。若未自动识别，点「设置」→「项目目录」选择包含 `start-workbench.ps1` 的目录。

## 主要操作

| 按钮 | 作用 |
|------|------|
| 启动工作站 | 启动本机后端（先确保数据库可用），轮询 `/health` 直到就绪 |
| 打开工作站 | 在嵌入窗口打开前端页面 |
| 停止工作站 | 安全停止后端（只停被认领的进程） |
| 重启工作站 | 停止后重新启动 |
| 查看日志 | 打开后端运行日志 |
| 浏览器打开 | 在默认浏览器打开前端地址 |
| 版本 | 显示后端 API 版本与兼容性 |
| 设置 | 配置项目目录 / 本地或云端 / 云端地址 / 自动启动 / 托盘 |

## 状态指示

- 顶部圆点 + 标签：整体状态（未启动 / 启动中 / 运行中 / 降级 / 已停止 / 失败）。
- 下方芯片：后端、数据库、前端、地址四项实时状态（每 2.5 秒轮询）。

## 托盘行为

- 关闭窗口时默认**最小化到托盘**（可在设置中关闭）。
- 托盘菜单可「显示主窗口」或「退出」。
- 若后端仍在运行，退出前会提示确认。

## 云端模式

设置中把「运行模式」改为「远程（云端地址）」，填入 HTTPS 地址并保存。此后启动器不管理本地后端/数据库，直接导航到云端。

## 常见问题

- **启动失败 / 数据库未就绪**：查看「查看日志」或 `%APPDATA%\ALE Workbench Launcher\logs`；数据库可重新部署：`powershell -File "C:\Program Files\ALE Workbench\launcher\deploy\deploy-mysql.ps1" -ProjectRoot "C:\Program Files\ALE Workbench"`。
- **端口被占用**：后端默认 8001、数据库默认 3307。若 3307 被其他服务占用，部署脚本会拒绝改动并提示，请在设置/脚本中改用空闲端口。
