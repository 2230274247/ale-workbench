# 快录交互与字段字典

默认 `/` 跳转 `/quick`，避免首页保存后更换组件丢失瞬时反馈。专业概览 `/professional` 与全部原路由保留。导航提供快录、历史、数据集、模板、AI实验室。

沿截图阅读顺序：实验信息（日期、当天次序、显眼材料、空起止时间、明确跨日、备注）→ 参数（外层循环、A组重复、源/Pulse ms/Purge s/Wait s/ΔP Pa、R1/R2/N2）→ 多行结果 → 真实保存。首次五列均空；外层1、组100和结果有效周期100仅为可编辑程序/周期建议，不预填设备工艺数值。

材料主键 quick_materials.material_id，保留规范名和别名数组。常用SiN/SiO₂快捷选择、搜索/自定义；名称不自动归一为等同物理材料。草稿可空，正式记录要求主材料，结果可独立覆盖材料。最近选择可从数据库持久化的历史记录或沿用上次取得。

程序与结果字段完整契约以 backend/app/quick_models.py 为准：动态有序数组保留每组/每步稳定 UUID；全空步骤 enabled=false；0与null分开；R1/R2/绝对压力/压差不互填。Pulse/Purge不会合并或自动改单位。输入使用原始文本缓冲，非法中文/小数在本格保留并提示；数字清理仅发生于提交副本。

步骤增/插/复制/左右移动、组排序、删除含数据确认；当前会话可见撤销及网格外Ctrl+Z。不接管输入框本身的原生撤销。参数区域横滚、标签固定、可键盘聚焦；隐藏标签在相对定位容器内避免自身造成页面溢出。表单按可用容器宽度折为单列，兼容真正浏览器200%缩放。

结果保持稳定 result_id；前后膜厚、独立有效循环、前膜厚来源、真实性、均匀性/定义、报告EPC、质量状态分开。后台Decimal计算 Δt=前−后，EPC=10Δt/N；N=0/未知时EPC=null，负EPC保留。前端仅预览，保存读取服务器确定值。承接值明确标记非本次实测，旧段改膜厚时提示参考待复核；累计沿显式结果链实时重算。

保存中锁按钮；失败保持表单；409可下载当前输入后重新加载。离开未保存页面确认，弹窗取消恢复焦点。复制/模板清空结果、来源、连续身份；继续下一段保留显式前段引用与参考来源。手动/Excel/稍后入口切换不丢输入。

主题复用海军蓝/青绿与现有冷色轻拟物变量；没有新增运行期UI库。测试专用 @axe-core/playwright 4.10.2（MPL-2.0）仅安装在 reports/ale_v2_2/qa-tools，不进入产品包。没有暗色模式，不新造暗色验收。

最终布局遵循用户截图：主表删除SiN/SiO₂快捷按钮、外层循环行、步骤操作行、增步骤/工艺组按钮。完整结构操作改在按需“编辑工艺结构”弹窗内使用独立草稿，应用后回主表保存。显示使用“膜厚测量”“样品标识”“薄膜材料”“刻蚀前/后膜厚”，不重复“结果1”前缀。保存期间原生fieldset锁定输入，失败解锁并聚焦错误。
