# 配置与部署

本文覆盖：环境变量、凭据文件、数据库、启动与端口、手机访问、常见故障、备份与升级。
所有示例中的路径以 `H:\ALE_AI` 为例，换机器时按实际目录替换。

## 1. 配置文件一览

| 文件 | 作用 | 是否提交 |
|---|---|---|
| `backend/.env` | 后端运行配置（密钥、数据库连接、部署标识） | **否**（模板 `.env.example`） |
| `database/.dbcreds` | MySQL 管理员凭据，仅建库/迁移用 | **否**（模板 `.dbcreds.example`） |
| `database/.appcreds` | 应用账号 `ale_app` / `ale_ro` 凭据，由建库脚本生成 | **否**（模板 `.appcreds.example`） |
| `backend/.setup-code` | 初始化首位管理员的一次性访问码，用后可删 | **否** |
| `backend/.ai-master-key` | AI 配置加密密钥（启用 AI 功能时生成） | **否** |

`.gitignore` 已覆盖以上全部路径，另排除 `storage/`（原始文件）、`mysql_data/`、`reports/`、`backups/`、`node_modules/`、`frontend/dist/`、虚拟环境。

## 2. 环境变量（backend/.env）

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `ALE_JWT_SECRET` | ✅ | 无 | 登录令牌签名密钥，**≥32 字符**；缺失或过短服务直接拒绝启动 |
| `ALE_DB_HOST` | | `127.0.0.1` | MySQL 地址 |
| `ALE_DB_PORT` | | `3307` | MySQL 端口（本项目默认非 3306） |
| `ALE_DB_NAME` | | `ale_workbench` | 生产库名；测试库必须以 `_test` 结尾 |
| `ALE_DB_PASSWORD` | | 取 `.appcreds` | 通常留空，由 `.appcreds` 提供 |
| `ALE_ENVIRONMENT` | | `production` | 仅 `production` / `testing` |
| `ALE_ENVIRONMENT_LABEL` | | `生产环境` | 界面上显示的环境名 |
| `ALE_INSTANCE_ID` | | `ale-workbench-production` | 实例标识，出现在页头会话信息 |
| `ALE_COOKIE_SECURE` | | `false` | 上 HTTPS 后改 `true`；本机 http 必须 `false`，否则登录 Cookie 不生效 |
| `ALE_ALLOWED_ORIGINS` | | 空 | 前后端不同源时的 CORS 白名单，逗号分隔 |
| `ALE_ORIGINALS_ROOT` | | `storage/` | 原始文件根目录 |

生成密钥：

```powershell
python -c "import secrets;print(secrets.token_urlsafe(48))"
```

修改 `.env` 后必须**重启后端**才生效。

## 3. 凭据文件格式

`database/.dbcreds`（管理员，建库/迁移用）：

```ini
user=root
password=你的MySQL_root密码
# host=127.0.0.1
# port=3307
```

`database/.appcreds`（应用账号，`apply_schema.py` 自动生成，多账号用 `[section]`）：

```ini
[ale_app]
user=ale_app
password=<自动生成>
host=127.0.0.1
port=3307
database=ale_workbench
```

后端按用户名 `ale_app` 选择账号；密码优先取 `ALE_DB_PASSWORD`，否则取该文件。

## 4. 数据库初始化顺序

```powershell
# 1) 建库 + 建账号 + 结构校验（幂等，可重复执行）
python database\apply_schema.py

# 2) 应用增量迁移 0001–0016（自动快照备份，失败不动库）
backend\.venv-win\Scripts\python.exe database\migrate.py

# 3) 查看迁移状态与校验
backend\.venv-win\Scripts\python.exe database\migrate.py --status
```

- 迁移只允许 `ale_workbench` 或显式 `*_test` 库；应用过的 SQL 校验和不一致会直接报错，不会静默重写。
- 启动器**不会**自动迁移；`/health` 通过不代表迁移完整。

## 5. 启动与端口

```powershell
.\启动工作台.cmd                                   # 默认 8001
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-workbench.ps1 -Port 8002
```

- 启动器只接受它自己启动的 uvicorn 单进程 loopback 监听；端口被别的程序占用时**拒绝启动**，不强杀。
- 运行记录：`backend/.runtime/server-<端口>.json`，错误日志：`server-<端口>.stderr.log`。
- 前端由后端直接托管 `frontend/dist`；改前端后需 `npm run build`，改后端需重启。

## 6. 手机访问（移动版 /m）

后端默认只绑定 `127.0.0.1`，手机无法直接连。三种方式：

1. **局域网（日常最方便）**：把启动命令的 `--host 127.0.0.1` 改为 `0.0.0.0`（或给启动器加参数），手机与电脑连同一 WiFi，访问 `http://<电脑IP>:8001/m`。注意同一局域网的人都能打开登录页，依赖账户密码保护。
2. **USB 转发（零暴露）**：安卓开启 USB 调试，执行 `adb reverse tcp:8001 tcp:8001`，手机浏览器打开 `http://127.0.0.1:8001/m`。
3. **公网 HTTPS**：云服务器或内网穿透，`ALE_COOKIE_SECURE=true`，并配置 `ALE_ALLOWED_ORIGINS`。上公网前务必确认账户权限与备份策略。

添加到主屏幕：Android Chrome 菜单「安装应用」；iOS Safari「分享 → 添加到主屏幕」。图标与启动页由 `frontend/public/manifest.webmanifest` 提供。

## 7. 常见故障

| 现象 | 原因与处理 |
|---|---|
| 启动即退出，提示 `Configure ALE_JWT_SECRET` | `backend/.env` 缺失或密钥短于 32 字符 |
| 登录后立刻掉线、反复要求登录 | `ALE_COOKIE_SECURE=true` 但用 http 访问；改回 `false` |
| `Application database account ale_app is not configured` | 未执行 `apply_schema.py` 或 `.appcreds` 丢失 |
| 页面空白 / 新功能不生效 | `frontend/dist` 未重建；执行 `npm run build` 后强刷（Ctrl+F5） |
| 端口被占用拒绝启动 | 换端口 `-Port 8002`，或确认占用者后再处理，切勿按端口名杀进程 |
| 批量导入提示材料不存在 | 材料必须先存在于材料目录，系统不自动创建 |
| 127.0.0.1 返回 502 | 本机 `HTTP_PROXY` 干扰；curl 加 `--noproxy '*'`，或临时清除代理 |

## 8. 备份

- 迁移前自动快照到 `backups/`（不入版本控制）。
- 手工逻辑备份建议：`mysqldump --single-transaction -P 3307 -u root -p ale_workbench > backup.sql`。
- 原始上传文件在 `storage/`，与数据库备份一起保存才能完整恢复。

## 9. 升级流程

```powershell
git pull
backend\.venv-win\Scripts\python.exe -m pip install -r backend\requirements.txt
cd frontend; npm ci; npm run build; cd ..
backend\.venv-win\Scripts\python.exe database\migrate.py
.\启动工作台.cmd
```

数据库结构变更只以新增迁移文件的方式落地，不修改已应用的 SQL。

## 10. 提交到 Git 前的自检

```powershell
git status --short
git check-ignore -v backend\.env database\.appcreds backend\.setup-code
```

确认没有 `.env`、凭据、`.setup-code`、`storage/`、`reports/`、`mysql_data/` 被加入暂存区。仓库建议保持 **private**，除非确认代码与文档可公开。
